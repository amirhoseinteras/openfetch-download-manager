# Contributing to OpenFetch

Thanks for improving an open-source project. Please open a focused issue describing a bug or suggested feature before making major changes.

1. Do not submit secrets, browser cookies, passwords, tokens, or third-party copyrighted assets.
2. Run python -m unittest discover -s tests -v and report any relevant results.
3. Keep pull requests small and describe behavior changes and testing.
4. Please be respectful; do not create artificial stars, downloads or meaningless pull requests.
